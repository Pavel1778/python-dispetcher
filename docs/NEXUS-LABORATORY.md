# NEXUS: файловая лаборатория, рабочие пространства, голос и GitHub

Это описание **фактически реализованной** части. Что не сделано — перечислено в
конце и в [NEXUS-AUDIT.md](NEXUS-AUDIT.md); не выдавайте эти пробелы за
готовность.

## Границы

- Всё, кроме GitHub-чтения, привязано к проекту и проверяется на backend в том
  же запросе, что читает строку. Чужой проект — `404`, не утечка.
- Загруженные байты лежат в PostgreSQL (`nexus_files`,
  `nexus_voice_notes`, `nexus_workspace_files`), **никогда** на диске сервера.
  Имя файла — метаданные, не путь: из него убираются разделители.
- Ничто загруженное не исполняется. Рабочее пространство — данные, не оболочка.
- Мутации требуют сессии с CSRF или machine bearer; чтения — сессии или bearer.

## Файловая лаборатория

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/v1/projects/{id}/files` | Загрузить файл (multipart, поле `file`) |
| GET | `/api/v1/projects/{id}/files` | Список файлов |
| GET | `/api/v1/projects/{id}/files/{file_id}` | Метаданные + превью (текст/изображение) |
| GET | `/api/v1/projects/{id}/files/{file_id}/download` | Скачать байты |
| DELETE | `/api/v1/projects/{id}/files/{file_id}` | Удалить файл |

- Размер загрузки ограничен `NEXUS_MAX_UPLOAD_BYTES` (по умолчанию 32 МиБ) и
  проверяется по `Content-Length` **до** чтения.
- Превью текста ограничено `MAX_PREVIEW_BYTES` (256 КиБ); при обрезке ответ
  содержит `truncated: true`.
- Скачивание всегда отдаётся как `attachment` с `X-Content-Type-Options:
  nosniff` и `Cache-Control: no-store`, а имя в `Content-Disposition`
  нормализуется (без управляющих символов и разделителей пути).

## Безопасная распаковка архивов

Поддерживаются `.zip`, `.tar`/`.tar.gz`/`.tgz`/`.tar.bz2`/`.tar.xz`, `.gz`,
`.bz2`, `.xz`. Модуль `orchestration/archive_safety.py` отклоняет **до записи
любой строки**:

- **Zip Slip / обход пути:** `../`, абсолютные пути, буквы диска (`C:`), UNC,
  `..\` (обратный слэш нормализуется первым).
- **Символические и жёсткие ссылки, device/FIFO:** отклоняются целиком.
- **Архивные бомбы:** потолки на число записей (2000), суммарный размер
  распаковки (256 МиБ), размер одной записи (64 МиБ) и коэффициент сжатия (200×,
  применяется только к архивам больше 1 МиБ, чтобы крошечный файл с большим
  коэффициентом не отклонялся зря). Потолок проверяется и по заявленному, и по
  **фактически прочитанному** размеру, потому что заявленный размер может лгать.
- **Глубина и длина имени** ограничены.

Отклонённый архив не создаёт рабочего пространства. Ограничения настраиваются
через `ArchiveLimits`.

## Рабочие пространства (Development Laboratory)

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/v1/projects/{id}/workspaces` | Создать пустое пространство |
| POST | `/api/v1/projects/{id}/workspaces/from-file` | Создать из архива (безопасно) |
| GET | `/api/v1/projects/{id}/workspaces` | Список |
| GET | `/api/v1/projects/{id}/workspaces/{ws}` | Список файлов |
| GET | `/api/v1/projects/{id}/workspaces/{ws}/files/{path...}` | Чтение файла |
| POST | `/api/v1/projects/{id}/workspaces/{ws}/files` | Создать/изменить файл (`path`, `text`) |
| DELETE | `/api/v1/projects/{id}/workspaces/{ws}/files/{path...}` | Удалить файл |
| GET | `/api/v1/projects/{id}/workspaces/{ws}/diff` | Unified-diff изменённых файлов |
| DELETE | `/api/v1/projects/{id}/workspaces/{ws}` | Удалить пространство |

- Путь нормализуется (`safe_workspace_path`), отклоняется всё, что может выйти
  за пределы пространства; в БД это повторно проверяется `CHECK`.
- При первой правке исходные байты сохраняются в `original_data`, поэтому diff
  показывает импортированную версию, а не предыдущую правку.

## Голос

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/v1/projects/{id}/voice` | Загрузить запись (multipart, поле `audio`, опц. `duration_ms`, `transcript`) |
| GET | `/api/v1/projects/{id}/voice` | Список заметок |
| GET | `/api/v1/projects/{id}/voice/{note_id}/audio` | Прослушать |

- Серверного распознавания речи **нет**. Если браузер прислал текст, он
  сохраняется с `transcript_engine="browser"` и не считается серверной проверкой.
  Без текста `transcript` — `null`, и UI так и показывает.
- Принимаются только аудио-типы; запись ограничена тем же лимитом загрузки.

## GitHub

Чтение (без записи):

| Метод | Путь |
|---|---|
| GET | `/api/v1/projects/{id}/github/repositories` |
| GET | `/api/v1/projects/{id}/github/repositories/{owner}/{name}` |
| GET | `.../{owner}/{name}/branches` \| `/commits` \| `/issues` \| `/pulls` |

Записи — **только через подтверждение**. Сначала создаётся предложение, затем
человек подтверждает:

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/api/v1/projects/{id}/github/repositories` | Предложить создание (`name`, `private`, `description`) |
| POST | `/api/v1/projects/{id}/github/repositories/{owner}/{name}/visibility` | Предложить смену видимости (`private`) |
| POST | `/api/v1/projects/{id}/actions/{action_id}/confirm` | Подтвердить (`token`) и выполнить один раз |
| POST | `/api/v1/projects/{id}/actions/{action_id}/cancel` | Отменить |
| GET | `/api/v1/projects/{id}/actions` | Ожидающие предложения |

Правила подтверждения:

- Предложение возвращает одноразовый `confirmation_token`; в БД хранится только
  его SHA-256. Неверный токен — `403`.
- Повторное подтверждение — `409`; действие не выполняется дважды.
- Предложения истекают (по умолчанию 900 с).
- **Публичность требует отдельного согласия:** `GitHubWriter.set_repository_visibility`
  отказывает в переводе в public без `acknowledge_public=True`, которое
  выставляется только в обработчике подтверждённого предложения. Даже при ошибке
  в вызывающем коде репозиторий не станет публичным случайно.
- Токен GitHub читается из `GITHUB_TOKEN`, не логируется и не возвращается;
  `GitHubWriter.__repr__` редактируется. Записи идут через отдельный класс
  `GitHubWriter`; путь только для чтения (`GitHubClient`) не умеет писать.

## UI

Вкладки «Лаборатория» и «GitHub»:

- **Лаборатория:** выбор проекта, загрузка файла, просмотр/скачивание/удаление,
  распаковка архива в пространство, список и правка пространств, diff, запись
  голосовой заметки через `MediaRecorder`.
- **GitHub:** список репозиториев, детали, кнопка смены видимости, форма создания
  и **диалог подтверждения** с отдельным предупреждением для public. Диалог
  ничего не делает, пока не нажато «Подтвердить».

## Миграции и развёртывание

`migrations/0011_file_lab.sql` аддитивна: создаёт `nexus_files`,
`nexus_workspaces`, `nexus_workspace_files`, `nexus_pending_actions`,
`nexus_voice_notes`, включает RLS и отзывает права у `PUBLIC`/`anon`/
`authenticated`. Применяется автоматически при старте, если `AUTO_MIGRATE` не
выключен; как и прежде, сначала проверьте бэкап и историю миграций на целевой
БД.

## Тестирование

```bash
TEST_SUPABASE_DB_URL="postgresql://.../disposable" \
  python -m pytest tests/test_archive_safety.py tests/test_file_lab.py \
                   tests/test_github_client.py -q -p no:cacheprovider
```

`test_archive_safety.py` не требует БД и проверяет каждое правило отказа
поимённо. `test_file_lab.py` идёт по реальному HTTP, реальному PostgreSQL и
реальному fake-GitHub и проверяет, что неподтверждённое действие не доходит до
GitHub (`gh.writes == []`).
